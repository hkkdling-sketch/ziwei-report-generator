# 紫微斗数报告生成器 · Ziwei Report Generator

用 [iztro](https://github.com/SylarLong/iztro) 的紫微斗数排盘引擎，把一份 JSON 输入渲染成结构化的 HTML 命盘报告。

**这是一个给命理从业者用的排版工具，不是算命服务。** 排盘由开源算法引擎完成，解读文案由使用者自己提供——工具只负责把它们拼成一份体面的报告。

## 设计原则

| 部分 | 由谁提供 | 说明 |
|---|---|---|
| 命盘数据（十二宫、主星、五行局、大限） | **iztro 算法引擎** | 真实排盘，不是大模型猜的 |
| 解读文案（共情 / 解读 / 三件事） | **使用者填在 JSON 里** | 工具不生成解读，只渲染 |

这两件事分开，是这个工具存在的理由：**排盘要准，解读要有个人风格**。把解读交给模板是最没价值的部分，所以这个工具干脆不碰。

## 报告结构

```
共情（先接住情绪）
  ↓
命盘概览 + 十二宫（给出凭据）
  ↓
解读（解释为什么会这样）
  ↓
三件可以做的事（落到行动）
  ↓
30 天内一次追问入口
```

结构按「安心」组织：先接住情绪，再给凭据，然后解释，最后落到行动。如果你自己的交付流程不同，直接改 `generate.js` 里的 `CSS` 和渲染函数即可。

## 跑起来

```bash
npm install          # 安装 iztro
node generate.js samples/sample-1.json -o out/sample-1.html
```

`out/` 下会生成 HTML，浏览器直接打开就能看。仓库里已带三份跑好的样张，见 `out/` 和 `sample-site/`。

## 输入格式

复制 `samples/sample-1.json`，改这几个字段：

| 字段 | 说明 |
|---|---|
| `brand` | 报告页眉显示的工作室/个人名号 |
| `title` | 报告标题 |
| `solar` | 阳历生日，如 `1995-3-21` |
| `timeIndex` | 时辰索引：0 早子 · 1 丑 · 2 寅 · 3 卯 · 4 辰 · 5 巳 · 6 午 · 7 未 · 8 申 · 9 酉 · 10 戌 · 11 亥 · 12 晚子 |
| `gender` | `男` 或 `女` |
| `theme` | 本次报告主题，如 `职场迷茫` |
| `empathy` | 开头共情段 |
| `reading` | 解读段落数组 |
| `actions` | 三件明确可做的事 |

## 目录

```
generate.js          主脚本：读 JSON → iztro 排盘 → 渲染 HTML
samples/             输入样例（3 份，数据为虚构示例）
out/                 渲染输出
sample-site/         一个可直接浏览的样张集合页
```
